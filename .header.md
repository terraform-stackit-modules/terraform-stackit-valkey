# Terraform STACKIT Valkey module

Terraform module which provisions a [STACKIT Valkey](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/valkey_instance) instance and its credentials on [STACKIT](https://www.stackit.de/en/).

Valkey is the successor to STACKIT's Redis offering (the `stackit_redis_*` resources are deprecated and will be removed after August 2027). Prefer this module over `terraform-stackit-redis` for new workloads.

This repository is not from the official STACKIT organization.

## Usage

```hcl
module "valkey" {
  source  = "terraform-stackit-modules/valkey/stackit"
  version = ">= 1.0.0"

  project_id     = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
  name           = "app-valkey"
  valkey_version = "7"
  plan_name      = "stackit-valkey-single-4"

  parameters = {
    sgw_acl          = "0.0.0.0/0"
    maxmemory_policy = "volatile-lru"
  }

  credentials = {
    app = {}
  }
}
```

See [`examples/basic`](./examples/basic) for a self-contained example (requires only `project_id`).

## Composite module

- `modules/instance` — the `stackit_valkey_instance` (toggled by `create_instance`).
- `modules/credential` — `stackit_valkey_credential` entries (`for_each` over `credentials`).

The root wires them together and, when `create_instance = false`, targets an existing instance via
`instance_id` for credential management.

## Notes

- Generated credentials (`password`, `uri`) are exposed via **sensitive** outputs.
- `credentials` is a map keyed by a **stable identifier**; the instance_id (known after apply when
  the instance is created here) is only a resource attribute, never a `for_each` key.
- Valkey (like Redis) has no separate database/user resources — access is via credentials
  (auto-generated username/password).

## Terratest

The `test/` directory holds a Terratest integration test that applies the `examples/basic` root module against a real STACKIT project (requires `STACKIT_SERVICE_ACCOUNT_KEY` and `STACKIT_PROJECT_ID`).

```bash
cd test
go mod init github.com/terraform-stackit-modules/terraform-stackit-valkey
go get github.com/gruntwork-io/terratest@v1.0.1
go mod tidy
go test -v -timeout 45m ./...
```
